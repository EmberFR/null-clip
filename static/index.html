02. Architecture & Capabilities

Engineered for Zero-Bloat Linux Gaming

01. Headless Memory Discipline

~120 MB Total RAM with the UI Closed

When you close the window, the GTK3 GUI process exits completely (0 MB UI overhead) and hands global hotkey listening to a compiled native C daemon (~0.8 MB RSS) alongside gpu-screen-recorder's H.264 RAM ring buffer. Tested and verified on a Lenovo ThinkPad T480.

null-clip (UI Closed: 0.8 MB C Daemon + GPU RAM Ring Buffer) ~120 MB RAM
OBS Studio Replay Buffer (Full Scene Compositor + Qt GUI Open) ~480 MB RAM
Electron / WebView Clippers (Resident Chromium Renderer) ~680 MB RAM
02. Zero SSD Wear

Driver-Level GPU Ring Buffer

Powered by gpu-screen-recorder talking directly to NVENC, VAAPI, or Vulkan. Gameplay stays in a strictly RAM-backed circular buffer (-replay-storage ram) until you press F8, preventing constant SSD writes and frame drops.

NVIDIA · NVENC Hardware H.264
AMD & Intel UHD 620 · VAAPI

04. Kernel-Native Automation

Auto-Titled by Game, Game-Only Watchdog & Kernel inotify

The millisecond gpu-screen-recorder finishes writing a clip, null-clip wakes via Linux libc inotify (IN_CLOSE_WRITE | IN_MOVED_TO) with zero disk polling. It inspects the active window across Hyprland (hyprctl), Sway (swaymsg), X11 (xdotool / xprop), and /proc to name and tag your clip automatically.

03. Installation & Packages

Install on Any Linux Distribution in 30 Seconds

null-clips.AppImage uses a FUSE-free ELF64 Type-2 header, so it launches directly on any x86_64 Linux distro and integrates cleanly with AppImage launchers like Shelly without requiring libfuse2. 

curl -fLO https://github.com/EmberFR/null-clip/releases/latest/download/null-clips.AppImage
chmod +x null-clips.AppImage
./null-clips.AppImage

Install required runtime packages with pacman and build the native package via the included PKGBUILD: 

sudo pacman -S --needed gpu-screen-recorder ffmpeg wl-clipboard curl python python-gobject gtk3
git clone https://github.com/EmberFR/null-clip.git && cd null-clip && makepkg -si

Install dependencies on Fedora or Nobara, then run ./install.sh to install the desktop entry, icon, and executable to ~/.local/bin/null-clips: 

sudo dnf install -y gpu-screen-recorder ffmpeg wl-clipboard curl python3 python3-gobject gtk3
git clone https://github.com/EmberFR/null-clip.git && cd null-clip && ./install.sh

Install GTK3 GObject introspection bindings and tools on Ubuntu, Debian, Linux Mint, or Pop!_OS, then run ./install.sh: 

sudo apt-get update && sudo apt-get install -y ffmpeg wl-clipboard curl python3 python3-gi python3-gi-cairo gir1.2-gtk-3.0
git clone https://github.com/EmberFR/null-clip.git && cd null-clip && ./install.sh
